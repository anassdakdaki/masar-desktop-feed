# Masar Desktop Releases

Public downloads and update metadata for the Masar POS desktop app. Application source is maintained separately.

## Downloads

- [Latest stable release](https://github.com/anassdakdaki/masar-desktop-feed/releases/latest)
- [All releases, including beta builds](https://github.com/anassdakdaki/masar-desktop-feed/releases)

Release assets include the Windows installer, a portable x64 archive, and update metadata. Choose a stable release for regular use; beta releases are marked as prereleases.

## Repository purpose

This repository is a distribution feed. The small source tree is intentional. Release tags, asset names, and update metadata are used by the desktop update process.
